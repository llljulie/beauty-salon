Сайт салона красоты «Шарм»

Учебный проект по разработке адаптивного сайта салона красоты с онлайн-записью и демонстрационным модулем оплаты.
О ПРОЕКТЕ
Салон красоты «Шарм» — небольшой салон с 4 мастерами и 7 услугами у каждого из них. Сайт нужен, чтобы разгрузить администратора, дать клиентам возможность записываться онлайн круглосуточно и презентовать услуги и мастеров.
Уровень реализации: рабочий прототип.
Заказчик: Салон красоты «Шарм».
Исполнитель: Команда 3.
Цель проекта: разработать и запустить адаптивный сайт салона красоты с онлайн-записью до конца семестра.

Функциональность:

Главная страница с презентацией салона.
Блок «Услуги» — 4 мастера с набором услуг с ценами и описанием.
Форма «Онлайн-запись» — форма записи: услуга, мастер, дата, время, имя, email.
Модуль оплаты (демонстрационный режим).
Админ-панель для просмотра заявок.

Технологии:
Frontend: HTML, CSS, JavaScript.
Backend: Python.
Хостинг: GitHub Pages.
Дизайн: Figma.
Трекер: YouGile.
